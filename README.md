# Threshold

Creators rarely know when monetization will come or what to do next. Threshold is a planned app that reads a creator's profile and builds a plan that answers both.

## Status

Idea stage. This repository holds no source code yet: no language, framework or target platform has been chosen, so there is nothing to install or run.

The project is listed, with its current status, on [gabrielebolognese.blog](https://gabrielebolognese.blog).

## Download

```bash
git clone https://github.com/gabrielebolognese/threashold.git
```

The repository name is spelled `threashold`; the project is called Threshold.
